# Daymark for Android

Download the signed APK from [GitHub Releases](https://github.com/RMAipassa/Daymark-Releases/releases/latest). Choose `Daymark-<version>.apk`, not a source-code archive. Android may ask you to allow installs from the app you used to open the APK.

Each release includes a SHA-256 checksum. Compare it with the APK's SHA-256 before installing. The expected Android signing certificate SHA-256 is `4421f8ff5d869b93474b7e732c29e088dc5dbc42502c407b707f9940c472dbec`.

[Daymark-update.json](https://raw.githubusercontent.com/RMAipassa/Daymark-Releases/main/Daymark-update.json) is the update feed. It becomes available after the first release and lists the APK filename, checksum, version name, and Android version code.
